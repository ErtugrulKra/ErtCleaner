# Security policy

## Supported versions

Only the latest GitHub Release of ErtCleaner receives security updates.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for an undisclosed vulnerability.

1. Prefer [GitHub Private Vulnerability Reporting](https://github.com/ErtugrulKra/ErtCleaner/security/advisories/new) on this repository (enable it in repository settings if the form is unavailable).
2. If private reporting is not enabled, email **ertugrulkra@gmail.com**.

Include the affected version, a clear description, and steps to reproduce. Do not attach exploit payloads that target third-party systems.

## Release integrity

- Download installers only from official [GitHub Releases](https://github.com/ErtugrulKra/ErtCleaner/releases)
- Verify the published SHA-256 checksum against the installer bytes
